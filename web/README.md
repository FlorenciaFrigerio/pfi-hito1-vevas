# Web del brazo ABB IRB 120

**Qué contiene:** un modelo 3D interactivo del brazo ABB IRB 120 para explorar sus piezas, conocer sus articulaciones y ver los componentes de una celda de trabajo.

**Cómo abrirla:** descargar el repositorio y abrir su carpeta en una terminal, teniendo Python instalado. Escribir `python -m http.server 8000` y después abrir <http://localhost:8000/web/> en el navegador para ver la web.
