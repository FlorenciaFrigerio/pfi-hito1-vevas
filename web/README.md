# Web del brazo ABB IRB 120

**Qué contiene:** un modelo 3D interactivo del brazo ABB IRB 120 para explorar sus piezas, conocer sus articulaciones y ver los componentes de una celda de trabajo.

**Cómo abrirla:** descarga el repositorio y, con Python instalado, abre una terminal en su carpeta principal y ejecuta `python -m http.server 8000`. Luego entra en <http://localhost:8000/web/> desde el navegador.
